Before clicking **"Final Submit"** on the NABL Portal, the Quality Manager must verify the following **Four Chronological Evidence Gates**:

```
[Day 0: QMS & SOPs Effective]
       │
       ├──► Gate 1 (Days 1–90): 90 Days Continuous Daily IQC + Environmental + Equipment + MU Calculation Logs across all 6 Depts
       │
       ├──► Gate 2 (Days 15–75): Participation & Receipt of >= 1 Completed PT/EQAS Cycle Report (NABL 163) with |Z| <= 2.0 (or closed CAPA)
       │
       ├──► Gate 3 (Days 75–85): Full-Scope Internal Audit (ISO 15189:2022 Cl. 8.8) + 100% Closure of all Internal Audit Non-Conformities
       │
       ├──► Gate 4 (Days 86–90): Management Review Meeting (MRM - Cl. 8.9) Reviewing Days 1–85 Data & Approving NABL 153 Submission
       ▼
[Day 91+: Submit NABL 153 Application on NABL Web Portal]
```
