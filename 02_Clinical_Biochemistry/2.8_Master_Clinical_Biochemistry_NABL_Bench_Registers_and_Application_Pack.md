## Section 1: Purpose & NABL Portal (`NABL 100 / NABL 112`) Application Readiness
This Master Departmental Dossier fulfills two mandatory NABL accreditation requirements for **Department 02: Clinical Biochemistry**:
1. **Turnkey `NABL 100` Portal Scope Submission Table:** Provides the complete parameter-by-parameter **Scope of Accreditation Matrix** (Analyte, Specimen Matrix, Standardized IFCC/NIST Examination Technique, Analytical Measuring Range [`AMR`], Expanded Measurement Uncertainty [`MU %` at $k=2$, `ISO/TS 20914`], and Controlled SOP Code) for all routine and specialized clinical chemistry parameters run on the **Bonavera Chem-400 (Primary)**, **Bonavera Chem-200 (Backup)**, and **ISE / Blood Gas Systems**.
2. **Annual Calculated-Parameter LIMS Equation Verification & 10 Print-Ready Bench Registers (`NABL 112`):** Provides the mathematical verification log for all LIMS-computed biochemistry equations (`CKD-EPI 2021 Race-Free eGFR`, `Friedewald & Martin-Hopkins LDL-C`, `Payne Albumin-Corrected Calcium`, `Anion Gap`, `Osmolal Gap`, `BUN`, `Indirect Bilirubin`, `Globulin & A:G Ratio`, `R-Factor`, `FIB-4`, `eAG`, `TSAT %`) and the **10 Mandatory Live Clinical Biochemistry Bench Registers**.

## Section 3: Annual LIMS Calculated-Parameter Equation Verification Protocol (`ISO 15189:2022 Clause 7.3.6`)
Per **NABL 112**, every calculated parameter generated by the LIMS must undergo **documented manual calculator cross-verification across 3 test cases (Low, Normal, High/Boundary)** annually and after any LIMS update:

| Calculated Parameter | Exact LIMS Mathematical Formula Verified | Mandatory Boundary / Suppression Rule Verified in LIMS | Verification Status |
| :--- | :--- | :--- | :---: |
| **1. `CKD-EPI 2021` eGFR (`2.3.2`)** | $142 \times \min(\frac{\text{SCr}}{\kappa}, 1)^\alpha \times \max(\frac{\text{SCr}}{\kappa}, 1)^{-1.200} \times 0.9938^{\text{Age}} \times [1.012 \text{ if Female}]$ | Auto-switches to **Bedside Schwartz ($0.413 \times \text{Height}_{\text{cm}}/\text{SCr}$)** if Age $< 18\text{y}$. | ✅ **100% Verified** |
| **2. `Friedewald` / `Martin-Hopkins` LDL-C (`2.4.5`)** | $\text{LDL-C} = \text{TC} - \text{HDL-C} - \frac{\text{TG}}{5}$ (or $\frac{\text{TG}}{\text{Adjustable Factor } 3.1\text{–}11.9}$) | **Hard LIMS Suppression (`CALC-SUPPRESSED`)** if $\text{TG} > 400\text{ mg/dL}$ $\to$ Auto-reflexes Direct `LDL-C`. | ✅ **100% Verified** |
| **3. `Payne` Corrected Calcium (`2.5.1`)** | $\text{Corrected Ca}_{\text{mg/dL}} = \text{Total Ca}_{\text{mg/dL}} + 0.8 \times (4.0 - \text{Albumin}_{\text{g/dL}})$ | Applied only when $\text{Albumin} < 4.0\text{ g/dL}$; recommends Direct $\text{iCa}^{2+}$ (`2.5.2`) in ICU/acid-base disorders. | ✅ **100% Verified** |
| **4. Serum Anion Gap (`AG`, `2.3.7`)** | $\text{AG} = [\text{Na}^+] - ([\text{Cl}^-] + [\text{HCO}_3^-])$; $\text{Alb-Corrected AG} = \text{AG} + 2.5 \times (4.0 - \text{Alb})$ | Flags Negative/Low `AG` ($< 3\text{ mmol/L}$) for paraproteinemia (`MM`) or halide/lithium toxicity. | ✅ **100% Verified** |
| **5. `R-Factor` & `FIB-4` Score (`2.2.1`)** | $R = \frac{\text{ALT}/\text{ULN}}{\text{ALP}/\text{ULN}}$; $\text{FIB-4} = \frac{\text{Age} \times \text{AST}}{\text{PLT}_{10^9/\text{L}} \times \sqrt{\text{ALT}}}$ | Uses age-adjusted upper cutoff ($\text{FIB-4} < 2.0$ if Age $\ge 65\text{y}$). | ✅ **100% Verified** |
| **6. `eAG`, `BUN`, `Indirect Bil`, `Globulin`, `A:G`, `TSAT %`** | $\text{eAG} = 28.7 \times \text{HbA1c} - 46.7$; $\text{BUN} = \text{Urea} \times 0.467$; $\text{TSAT} = \frac{\text{Fe}}{\text{TIBC}} \times 100$ | Suppresses Indirect Bilirubin if Direct $>$ Total (delta-bilirubin check). | ✅ **100% Verified** |
